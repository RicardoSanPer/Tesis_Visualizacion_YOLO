# Anexos
Este directorio contiene archivos suplementales.

## Casos
Contiene los archivos producidos por el componente de extracción para los tres estudios de casos, excluyendo los archivos vdb. Los archivos .blend son omitidos en el repositorio.

## Pruebas_Rendimiento
Contienen las métricas capturadas por las pruebas de rendimiento de los componentes, compiladas en formato JSON. 

### Extracción
Compiladas en cuatro archivos para diferentes formatos de salida (png, jpg, tiff, vdb). Cada archivo JSON contiene los resultados compilados para cada archivo de entrada usado, con métricas de tiempo de ejecución, tamaño de archivos producidos, diferencia de presición, así como parámetros de ejecución.

### Visualización
Los resultados están organizados en el archivo JSON por el archivo de entrada de cada ejecución. Compila tiempos de renderizado para escenas incrementalmente complejas. Incluye ejemplos de las escenas renderizadas.

## Renders
Renders de ejemplo del componente de visualización.
