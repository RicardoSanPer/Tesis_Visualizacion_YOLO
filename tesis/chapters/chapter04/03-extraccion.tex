\section{Extracción de salidas intermedias}
Una vez implementado el módulo de ejecución, el siguiente componente a desarrollar es el de 
extracción. La función principal de este módulo es registrar los ganchos de ejecución posterior 
(\textit{forward hooks}) en el modelo para capturar las salidas intermedias de la red, así como 
extraer metadatos estructurales (arquitectura, parámetros de cada capa, y tensores de entrada y 
salida) para convertirlos a un formato intermedio dentro del entorno de Python.
\medskip

De forma análoga al módulo de ejecución, el componente de extracción se concibió mediante la clase 
\textit{ModelExtractor}. Esta clase recibe como parámetro de entrada una instancia de 
\textit{ModelExecutor} y desempeña dos funciones fundamentales:
\medskip

La primera consiste en configurar los \textit{forward hooks} sobre la arquitectura del modelo 
para interceptar los tensores generados en las capas de interés, tales como las capas 
convolucionales y de \textit{Max-Pooling}. Dichos tensores se almacenan 
en una estructura de diccionario indexada por el nombre o identificador de la capa de origen.
\medskip

La segunda función se encarga de extraer la metadata de la red estructurada por capas. Esta 
información abarca la topología de la red (específicamente las conexiones y flujo de datos entre 
capas) y los hiperparámetros de configuración, como el tipo de capa, número de canales de 
entrada y salida o el tamaño del núcleo (\textit{kernel}) de convolución. Como rasgo común, 
el registro de cada capa indica las capas subsecuentes con las que se conecta y un atributo 
booleano que señala si los tensores de dicha capa fueron capturados.
\medskip

Los datos generales extraídos por el módulo comprenden:
\begin{itemize}
    \item \textit{confidence}: el umbral de confianza utilizado por el modelo durante la inferencia.
    \item \textit{nms}: el valor del supresor de no máximos (\textit{Non-Maximum Suppression})
    utilizado durante la evaluación de las cajas de predicción.
    \item \textit{classes}: la lista de los nombres de clases de la red.
    \item \textit{layers data}: la estructura con los metadatos específicos de cada capa.
    \item \textit{layers}: el conjunto de tensores extraídos de las capas intermedias durante 
    la inferencia.
    \item \textit{boxes}: las cajas delimitadoras de predicción (\textit{bounding boxes}) generadas 
    a la salida del modelo.
    \item \textit{input image, output image}: las imágenes de entrada procesada y de salida 
    generada por el modelo.
\end{itemize}

Por su parte, los atributos específicos extraídos por cada capa incluyen:
\begin{itemize}
    \item \textit{type}: el tipo o categoría de la capa (e.g., convolucional, \textit{Max-Pooling}).
    \item \textit{data}: indicador booleano que especifica si se capturaron tensores para esta capa.
    \item \textit{connections}: la lista de capas subsecuentes a las que se conecta.
    \item \textit{input channels, output channels}: el número de canales de entrada y salida de las 
    capas convolucionales.
    \item \textit{kernel size}: el tamaño del núcleo (\textit{kernel}) de las capas convolucionales 
    y de \textit{Max-Pooling}.
    \item \textit{stride}: el paso o desplazamiento del \textit{kernel} en las capas convolucionales
     y de \textit{Max-Pooling}.
    \item \textit{padding}: el relleno o bordes aplicados en las capas convolucionales y de 
    \textit{Max-Pooling}.
\end{itemize}

Adicionalmente se extraen las cajas de detección de salida de la red.
