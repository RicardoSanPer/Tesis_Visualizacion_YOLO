\section{Procesamiento de Datos}
El módulo de formato e intercambio se implementa como una clase bajo el nombre
\textit{Model Exporter}. Tomando como parámetro de constructor una instancia de
la clase de extracción, su propósito es transformar los datos a un formato intermedio
y exportarlos como archivos al disco.
\medskip

Para transformar los tensores, el módulo convierte los tensores extraídos a un
arreglo de numpy de floats de 32 bits, y elimina la dimensión extra que los tensores
suelen tener para obtener un arreglo tridimensional. Posteriormente crea una
cuadrícula de OpenVDB a partir de este arreglo, aplica algunas transformaciones lineares
para que se conforme con el sistema de coordenadas de Blender, y exporta la cuadrícula
como un archivo \textit{.vdb} bajo el nombre de la capa.
\medskip

Por su parte, los metadatos de las capas y la red son exportados en formato JSON
bajo el nombre de archivo \textit{manifest}.
